# Flat price prediction

Школьный проект для предсказания цены квартиры по параметрам.

Что уже есть:

- простой парсер объявлений с Яндекс Недвижимости;
- анализ данных и обучение модели в `src/model.ipynb`;
- CatBoost для предсказания цены;
- отдельные модели CatBoost для нижней и верхней границы интервала;
- метрики качества модели.

## Как запустить

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Парсинг объявлений:

```bash
python src/parser.py --pages 1
```

Я пробовала ЦИАН и Домклик, но они часто включают защиту от автоматических
запросов: ЦИАН показывает капчу, а Домклик может отдавать ошибку 401. Поэтому
для рабочей версии оставлен Яндекс, потому что с него можно получить карточки
обычным запросом.

Вся работа с моделью находится в ноутбуке:

```text
src/model.ipynb
```
