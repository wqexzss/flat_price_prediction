# Flat price prediction

Предсказание цены квартиры по параметрам

Что сейчас есть:

- парсер объявлений с Яндекс Недвижимости для дальнейшего взаимодействия с ним до 23 мая
- анализ данных и обучение модели в `src/model.ipynb`
- CatBoost для предсказания цены, обученный на датасете из kaggle
- отдельные модели CatBoost для нижней и верхней границы интервала
- метрики качества модели

К 23 мая добавим:
- датасет из реальный данных, которые парсятся с сайтов. На нём будет обучена модель
- Telegram бот, куда пользователь сможет вводить параметры своей квартиры и получать её примерную стоимость

## Как запустить

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Парсинг объявлений:

```bash
python src/parser.py --pages 1
```

Вся работа с моделью находится в ноутбуке:

```text
src/model.ipynb
```

Запуск бота:

```text
python src/bot.py
```
